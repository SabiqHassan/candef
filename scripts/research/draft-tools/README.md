# Drafting helpers (batches 5 to 9)

Small scripts used to draft the 100-company program. Run them **from the repository root** (the worktree that holds the work; set `CANDEF_REPO` to override). They read `research-cache/` (gitignored: government CSVs, the federal corporations file, captures) and never write anything but `research/` files, so every record they write is `proposed`. Nothing here approves or publishes.

| Script                                                 | What it does                                                                                                                                                                                                                                              |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lookup.py <BN or name regex>`                         | Looks a business number or name up in the federal corporations files (`research-cache/corporations-canada/2026-10-16`).                                                                                                                                   |
| `def.py <BN> "<vendor regex>"`                         | Lists National Defence contract rows (by vendor name, grep-fast) and defence grant rows (by business number). Prints no buyer contact fields.                                                                                                             |
| `gr.py g <BN regex>` / `gr.py c <vendor regex>`        | Prints grant rows (ref, amendment, city, postal, value, title) or contract rows.                                                                                                                                                                          |
| `addsrc.sh <url> <kind> <publisher> <title> [YYYY-MM]` | Registers a government page as a source, copies the Government of Canada permissions (terms read 2026-10-15), captures it. **Government pages only**; for any other host read robots.txt and the terms first.                                             |
| `cap.py <sourceId> "<keyword>" [chars]`                | Prints the text around a keyword in a saved capture, so claims can be checked against what was actually read.                                                                                                                                             |
| `terms.py <base url>`                                  | Reads only robots.txt and the first legal page of a host and prints the sentences about automation and copying. Use it **before** fetching anything else from a company site.                                                                             |
| `setperm.py`, `orgperm.py`                             | Copy a permissions block from a template source; write the OrgBook BC "Access Only" block (capture denied, API reads allowed).                                                                                                                            |
| `gen.py <spec.json>`                                   | Writes `research/orgs/<slug>.yaml` from a JSON spec (legal name, registry ids, head office, classification, eligibility with cited rows, ledger); run `candef new company "<name>"` first. The specs themselves are not kept: the records are the output. |

Spec shape (see `gen.py`): `slug, card, note, name, legal, corp|bn, hq{city,prov,postal,comment,src,registry}, class, class_src, elig{rationale,boundary,contracts[[ref,procurement_id]],grants[[ref,amendment]],src,decision,weapons}, more[extra facts], extra_regs, rounds_yaml, ledger`.

Set `CANDEF_AUTHOR` (for example `agent:claude-code/claude-opus-5-5`) and `CANDEF_DATE` (`YYYY-MM-DD`) before `gen.py` and `addsrc.sh`; without them they write the batch 5 to 9 defaults (Sonnet, 2026-10-21).

Then: `npx prettier --write research`, `npx tsx pipeline/cli/candef.ts validate`, write `docs/verification/batchN/cards.json` and `independence.json`, `npx tsx scripts/research/blind-verification.ts package --cohort batchN` (grouped prompts by default), `npx tsx scripts/research/clearance.ts --cohort batchN` as a preview.
